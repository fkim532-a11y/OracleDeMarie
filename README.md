# Oracle de Marie

Application Android de guidance spirituelle inspirée de la Vierge Marie :
carte du jour parmi 33 cartes, tirage de 3 cartes (Corps, Âme, Esprit),
14 prières avec minuteur de méditation, paroles de Marie, journal de vos
tirages. Sans publicité, hors ligne : aucune donnée n'est envoyée nulle part.

*English below.*

## Installer

- [Google Play](https://play.google.com/store/apps/details?id=com.kim.oraclemarie)
- F-Droid : bientôt

## Compiler

    ./gradlew assembleRelease

Sans fichier `keystore.properties`, l'APK sort non signé.
Android 8.0 (API 26) minimum.

## English

Android spiritual guidance app inspired by the Virgin Mary: daily card among
33 cards, 3-card draw (Body, Soul, Spirit), 14 prayers with a meditation
timer, words of Mary, a journal of your draws. No ads, works offline: no
data is sent anywhere.

- Install from [Google Play](https://play.google.com/store/apps/details?id=com.kim.oraclemarie); F-Droid coming soon.
- Build with `./gradlew assembleRelease` (unsigned APK without `keystore.properties`). Android 8.0 (API 26) or later.
